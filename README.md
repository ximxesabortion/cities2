# Cities: Skylines II Mods

Public source for Cities: Skylines II mods by
[ximxesabortion](https://github.com/ximxesabortion).

## Map Editor Bridge [BETA]

Adds the base game's familiar construction toolbar and asset menus to the Map
Editor while preserving native placement, snapping, camera controls, road
renaming, and supported optional-mod integrations.

- [Source and documentation](map-editor-bridge/)
- [Paradox Mods](https://mods.paradoxplaza.com/mods/152595/Windows)
- PDX ID: `152595`

## Stacklight [BETA]

A compact, draggable diagnostic viewer and active mod-tool shelf. It groups
repeated records, keeps low-grade notices separate from errors, scopes
saved-map diagnostics to the active map, and creates privacy-sanitized reports.
It is useful for players troubleshooting a playset and for mod authors checking
their own creations.

- [Source and documentation](stacklight/)
- [Paradox Mods](https://mods.paradoxplaza.com/mods/152734/Windows)
- PDX ID: `152734`

## Building

Each project includes its own README, publishing notes, UI package, C# project,
and release builder. Cities: Skylines II's official modding toolchain is
required for the final game-compatible build.

Generated binaries, toolchain caches, local installations, release archives,
decompiled game code, and personal save data are intentionally excluded.

## Status

Both mods are beta software. Back up important maps and saves before testing
editor tooling. Issues and pull requests are welcome; include a privacy-checked
Stacklight report when it helps reproduce a problem.

No license grant is implied by source availability. A formal open-source
license can be added separately.
