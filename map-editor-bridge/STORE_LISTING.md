# Map Editor Bridge [BETA]

## Short description

Adds normal construction menus, reliable road renaming, and optional native
Tree Controller, Recolor, and Road Builder support to the Map Editor.

## Store description

Map Editor Bridge brings the base game's familiar construction toolbar and
asset menus into the Map Editor.

Select normal roads, networks, buildings, services, landscaping, and other
placeable assets using the same menu structure used in gameplay. The bridge
hands each selection back to the editor's native placement context, preserving
editor previews, snapping, curve modes, elevation controls, and camera input.

Features:

- Normal construction toolbar and searchable asset grids in the Map Editor
- Native road and object placement tools
- Native, save-safe renaming for a selected road, with automatic-name restore
- Protection against malformed null asset-pack badge references in the stock
  editor prefab picker
- A dedicated **Build menus** button to hide or restore the construction UI
- A secondary **Mod list** drawer naming every supported optional integration
- Verified optional **Road Builder [BETA]** integration (PDX 87190): open its
  native editor tool from **Mod list**, then use generated roads through the
  normal bridged road menus
- Verified optional **Recolor** integration (PDX 84638): open Recolor's native
  editor Color Painter from **Mod list**
- Verified optional **Tree Controller** integration (PDX 75993): its vegetation,
  age, brush, seasonal, and wind controls remain available through the normal
  Landscaping and Vegetation menus
- A compact draggable **Move It** launcher near the lower-left editor tools
- Population, economy, traffic, and other gameplay simulation systems remain off

Supported optional integrations:

- **Image Overlay** (PDX 74539)
- **Anarchy** (PDX 74604)
- **Better Bulldozer** (PDX 75250)
- **529 Tiles** (PDX 74328)
- **Move It** (PDX 74324)
- **Network Tools [Early Access]** (PDX 133736)
- **Tree Controller** (PDX 75993)
- **Recolor** (PDX 84638)
- **Road Builder [BETA]** (PDX 87190)
- **Unified Icon Library** (PDX 74417, recognized dependency)

The construction-menu bridge has no required mod dependencies. The **Mod list**
names the supported integrations and leaves each mod's own code in control.
Road Builder and its own dependencies are required only for Road Builder
features; they are not required to use Map Editor Bridge.
